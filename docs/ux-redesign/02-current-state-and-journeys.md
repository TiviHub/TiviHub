# Current State and Key Journeys

## Confirmed product areas

The current application includes:

- Home
- Live TV
- Movies
- Series and episodes
- Library
- Settings
- M3U URL and file sources
- Xtream-compatible sources
- XMLTV guide support
- Optional DRM configuration
- Search
- Favorites and watch progress
- Playback dialogs and inline live playback
- Source refresh and catalog caching
- Light, dark, and system themes
- Local data and backup/diagnostics functionality

## Journeys to audit

### First launch

- Is the purpose of TiviHub clear?
- Is adding the first source the obvious next action?
- Is the bring-your-own-authorized-source model understandable?
- Does decorative content support the task or delay it?

### Add or edit a source

Review M3U URL, local M3U file, Xtream, playlist naming, credentials, guide URL, DRM options, validation, progress, cancellation, success, and failure recovery.

### Browse and discover

Review Live TV groups, guide data, Movies, Series, episodes, search, filters, sorting, favorites, watchlist, and Continue watching.

### Playback

Review Watch, Resume, Replay, loading, buffering, DRM errors, unsupported media, stream errors, closing playback, Back behavior, and progress saving.

### Library

Review the distinction between favorites, watchlist, watching, watched, and recently watched. Confirm that actions and statuses are understandable without relying on icons alone.

### Settings and source management

Review source switching, editing, deletion, refresh warnings, backup/restore, themes, adult-content settings, subtitles, diagnostics, and updates.

## Audit method

For each journey, record:

- User goal
- Entry point
- Steps
- Expected result
- Current friction
- Evidence
- Severity
- Proposed improvement
- Validation method

Separate confirmed observations from hypotheses that require user testing.
