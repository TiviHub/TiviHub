# Screen reader pass (T12) — maintainer, optional

Status: not performed. If you skip it, the findings note says so.

Use NVDA (free, Windows) with the installed TiviHub app. Turn the speech viewer on (NVDA menu > Tools > Speech viewer) so you can paste what was announced. About 20 minutes.

For each step, write what was announced and mark OK, unclear, or broken.

| # | Step | Expected | Announced | OK / unclear / broken |
|---|------|----------|-----------|------------------------|
| 1 | Start the app | "Opening your library" dialog is announced, then focus lands somewhere sensible when it closes | | |
| 2 | Move through the navigation with Tab | Each item announced with name and, for the current page, its selected state | | |
| 3 | Open Settings, choose "Add source" | Dialog announced with its title; fields have labels; required fields announced | | |
| 4 | Fill in an M3U URL and connect | Progress and the result are announced (not silent) | | |
| 5 | Open Movies, move to a movie card | Card announces title, year, rating; favorite and watchlist buttons have clear names | | |
| 6 | Use the sort and category dropdowns | Announced as combo boxes with current value; options readable with arrow keys | | |
| 7 | Press Ctrl+K and search | Dialog announced; result count or result list announced as you type | | |
| 8 | Play a stream | Dialog announced; controls (play, volume, speed, quality) have names; errors are announced | | |
| 9 | Press Escape in each dialog | Dialog closes and focus returns to where you were | | |
| 10 | Open Library and Downloads | Page title and empty states are read | | |

Also note anything that is read twice, read in the wrong order, or not read at all.
