## TiviHub v2.2.0

TiviHub on Windows can now update itself: one click installs the new version and restarts the app.

### Highlights

- Update in the app (Windows): when a new version is available, **Settings → Application updates** shows "Update to vX.Y.Z". TiviHub downloads the update, checks that it is signed by us, installs it and restarts. No browser download, no installer to open yourself. If that does not work, it falls back to opening the download as before.
- Only stable releases are offered, never betas.
- Linux and macOS keep the download button, which opens the installer or package from the release page.

### Platform and privacy

- To get the first in-app update you need to install this version yourself once; earlier versions cannot update themselves.
- The update check and download talk to GitHub only. Nothing about you or your sources is sent.
- The installer is still unsigned for Windows, so the first install may show an unknown-publisher or SmartScreen warning. Updates are verified with TiviHub's own update signature.
