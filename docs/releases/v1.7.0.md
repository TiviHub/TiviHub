## TiviHub v1.7.0

This release adds a Downloads page and clearer empty and expired-playlist states.

### Highlights

- Add a Downloads page for saving and managing downloaded content.
- Add dedicated empty states for the Home page and for when no source is configured.
- Show a clear message when an Xtream playlist account has expired.
- Refine desktop window controls, global search, Live guide, and playback dialog behavior.

### Platform and privacy

- Windows 10/11 (x64) desktop installer using WebView2.
- Linux x64 AppImage and `.deb`, plus macOS arm64 and x64 `.dmg` packages.
- Playlists, credentials, catalogs, favorites, playback progress, settings, and diagnostic history stay on the device. TiviHub has no application server or account system.
- Playback, catalog, guide, and subtitle requests go directly from the app to the configured provider or service.

Use only sources and content you are authorized to access and follow applicable law and provider terms.
