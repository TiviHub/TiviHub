## TiviHub v1.5.0

This release refreshes the desktop experience, improves large-playlist handling, and adds broader automated coverage.

### Highlights

- Redesign the desktop app for Windows, macOS, and Linux, with updated navigation, home, catalogs, detail pages, library, and settings.
- Give the home screen a clear empty-library state and prioritize the most recently updated in-progress title for resuming, including items from other sources.
- Unify loading and progress feedback across startup, playlist import and refresh, stream checks, and playlist deletion.
- Speed up large playlist deletion by increasing bounded delete batches while retaining progress updates.
- Improve catalog handling for large Xtream playlists, including lazy episode loading and import diagnostics that record aggregate, privacy-safe summaries.
- Expand automated coverage for core user flows, catalog scale, and large IndexedDB playlist deletion.
- Refresh the website presentation and simplify project documentation to keep release notes.

### Platform and privacy

- Windows 10/11 (x64) desktop installer using WebView2.
- Linux x64 AppImage and `.deb`, plus macOS arm64 and x64 `.dmg` packages.
- Playlists, credentials, catalogs, favorites, playback progress, settings, and diagnostic history stay on the device. TiviHub has no application server or account system.
- Playback, catalog, guide, and subtitle requests go directly from the app to the configured provider or service.

Use only sources and content you are authorized to access and follow applicable law and provider terms.
