## TiviHub v1.8.0

This release moves the desktop app's storage from the webview's IndexedDB to SQLite.

### Highlights

- Desktop data now lives in a SQLite database in the app data folder, so the webview can no longer silently wipe it.
- On first launch your existing data is copied over and checked against the original before the app switches to SQLite. Your old data is left untouched.
- Source credentials are encrypted with a key held in the operating system keychain (a key file is used where no keychain is available).
- Xtream stream URLs are no longer stored with your account login in the database files.
- The startup screen now shows only while the library is actually loading.

### Good to know

- The first launch after updating takes longer while your data is copied.
- Going back to an older version opens its old data and does not include changes made after updating.
- M3U stream URLs are stored as your provider supplies them.

### Platform and privacy

- Windows 10/11 (x64) desktop installer using WebView2.
- Linux x64 AppImage and `.deb`, plus macOS arm64 and x64 `.dmg` packages.
- Playlists, credentials, catalogs, favorites, playback progress, settings, and diagnostic history stay on the device. TiviHub has no application server or account system.
- Playback, catalog, guide, and subtitle requests go directly from the app to the configured provider or service.

Use only sources and content you are authorized to access and follow applicable law and provider terms.
