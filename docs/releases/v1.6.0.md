## TiviHub v1.6.0

This release adds external ratings and popular catalogs, improves subtitle search reliability, and makes movie and series details easier to explore.

### Highlights

- Add MDBList-powered external ratings, summaries, and popular catalogs, with cached results and shared API rate-limit protection.
- Improve OpenSubtitles discovery and playback with cached search results and downloads, support for extensionless subtitle filenames, and bounded request timeouts.
- Add direct links in Settings for finding OpenSubtitles and MDBList API keys.
- Enrich movie and series detail pages with poster backdrops and a nine-item “Keep Exploring” row.
- Improve series details with a Season 1 default and season/episode counts based on fetched episode data.
- Reset scroll when opening a detail page and support mouse side-button back/forward navigation.

### Platform and privacy

- Windows 10/11 (x64) desktop installer using WebView2.
- Linux x64 AppImage and `.deb`, plus macOS arm64 and x64 `.dmg` packages.
- Playlists, credentials, catalogs, favorites, playback progress, settings, and diagnostic history stay on the device. TiviHub has no application server or account system.
- Playback, catalog, guide, and subtitle requests go directly from the app to the configured provider or service.

Use only sources and content you are authorized to access and follow applicable law and provider terms.
