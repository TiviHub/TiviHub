## TiviHub v1.2.0-beta.1

This beta improves catalog browsing, refresh behavior, and subtitle controls for the Windows desktop player.

### Highlights
- Sort movies and series by latest added, title, release year, or rating, with Latest Added as the default.
- Hide adult content across movies, series, and live TV with a device-local setting.
- Keep remote catalogs cached locally, refresh them automatically every 24 hours, or refresh manually. Settings show each source's last successful refresh.
- Improve catalog filtering responsiveness for large libraries.
- Import subtitles and search OpenSubtitles for movies and series; live TV keeps its provider-supplied subtitle tracks.
- Support M3U playlists up to 200 MB and Xtream API responses up to 200 MB, with the limits shown when adding a source.
- Add app screenshots to the README and link both website download buttons directly to the Windows installer.

### Platform and beta notes
- Windows 10/11 (x64) installer using WebView2. Windows is the only released platform; Linux is not available and macOS is not currently targeted.
- Catalogs, settings, and library data remain on the device. Playback and subtitle requests go directly to their configured providers.
- Catalog-year sorting depends on release-year metadata supplied by the source; entries without usable years sort after dated titles.
- The installer is unsigned, so Windows may show an unknown-publisher or SmartScreen warning. Playback compatibility depends on provider authorization, network, codecs, and WebView2.

This is an early beta; features may change and issues may occur. Use sources and content you are authorized to access.
