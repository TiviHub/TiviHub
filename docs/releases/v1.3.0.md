## TiviHub v1.3.0

This is the first stable release of the TiviHub Windows desktop player.

### Highlights

- Search across your library from one place, including live TV, movies, series, and saved items.
- Keep large catalogs responsive with incremental catalog processing and local caching.
- Refresh catalogs automatically or on demand, with safer handling when a provider returns an unexpectedly smaller or invalid catalog.
- Check a selected live-TV group for stream availability, with progress and cancellation controls.
- Automatically try the browser's native HLS playback path when Shaka Player cannot play a supported HLS stream.
- Download a recent, privacy-conscious diagnostics report from Settings. Reports are generated locally and omit titles, source names, URLs, credentials, raw error messages, and stack traces.
- Browse Movies and Series with horizontal top-10 shelves for newest and best-rated titles when the source provides the required metadata.
- Simplify the app navigation and manage sources from Settings.

### Platform and privacy

- Windows 10/11 (x64) desktop installer using WebView2. Windows is the only released platform; Linux and macOS are not supported.
- Playlists, credentials, catalogs, favorites, playback progress, settings, and diagnostic history stay on the device. TiviHub has no application server or account system.
- Playback, catalog, guide, and subtitle requests go directly from the app to the configured provider or service.
- The installer is unsigned, so Windows may show an unknown-publisher or SmartScreen warning. Playback compatibility depends on provider authorization, network access, codecs, and WebView2.

Use only sources and content you are authorized to access and follow applicable law and provider terms.
