# Code of Conduct

## Our commitment

TiviHub welcomes contributions from people with different backgrounds and experience. We aim to make participation respectful, constructive, and free from harassment.

## Expected behavior

- Be respectful and considerate in issues, reviews, discussions, and contributions.
- Critique ideas and code constructively; do not attack people.
- Respect privacy. Do not post playlist credentials, private URLs, personal information, signing material, or private screenshots.
- Focus feedback on improving the project and helping others participate.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, sexualized conduct, and publishing another person's private information are not acceptable.

## Enforcement

Project maintainers may edit or remove content and may restrict participation when behavior violates this Code of Conduct. To report a concern, contact a maintainer privately through GitHub. For security vulnerabilities, follow [SECURITY.md](./SECURITY.md) instead of filing a public issue.

This Code of Conduct applies to project spaces, including issues, pull requests, discussions, and project-related communication.
